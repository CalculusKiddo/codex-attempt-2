# The hunt for Bismarck

A simple five-minute animated documentary timeline template, covering 18–27 May 1941.

**Watch:** download `bismarck-timeline.mp4` using GitHub's **View raw** or **Download raw file** button. GitHub may not play repository video files inline.

- MP4 container, H.264 video, 1280 × 720, 12 frames per second, 5:00 duration.
- Ten 30-second chapters, each with three timed captions.
- Simplified shaded 3D ship forms, aircraft, moving route markers, wave lines, attack indicators, transitions, and a persistent timeline.
- Silent template; no narration or music is included.
- Ships, maneuvers, distances, and map outlines are illustrative rather than scale reconstructions. The cause of the sinking is summarized without assigning a precise share to combat damage versus scuttling.

## Edit and render

On macOS with Xcode Command Line Tools, open `render.swift` and edit the `chapters` array. Camera/projection and drawing functions are in the same file.

```sh
clang -O3 -DNDEBUG -Wno-pointer-to-int-cast -c encode.c -o encode.o
swiftc render.swift encode.o -o render
./render .
```

Run `./render . --preview` to create a single preview frame and a one-frame MP4. This replaces the output MP4; run the full render again afterward.

`encode.c` converts the rendered pixels to YUV420 and writes H.264 into MP4 without an installed video application or downloaded runtime dependencies. The encoder headers are vendored with their original public-domain notices. The Apple ARM intrinsic alias and private symbol aliases are defined in `encode.c`.
